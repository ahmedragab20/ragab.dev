A terminal promises **clear input**, **clear output**, and no mystery-meat
navigation.

That contract is why terminal aesthetics still feel honest on the modern web —
especially for builders.

## Precision over decoration

| Promise | Why it matters |
| --- | --- |
| Prompt | You always know where to type |
| History | Muscle memory compounds |
| Themes | Personality without layout churn |
