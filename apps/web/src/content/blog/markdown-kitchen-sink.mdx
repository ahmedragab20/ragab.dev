## Edge cases

Empty-ish emphasis neighbors: word**bold**word and word`code`word.

Special characters: &lt;angle&gt; &amp; ampersand — also raw & in text: a & b.

HTML entity in code: `a < b && c > d`

## Checklist for visual QA

When you open this post, confirm:

1. Title + meta chrome above the MDX body
2. Heading hash prefixes (`#`, `##`, `###`)
3. List markers (▸ and numbered)
4. Table borders / scroll on narrow widths
5. Code blocks scroll horizontally if needed
6. Images load, captions under them
7. Callout border colors differ by type
8. YouTube and map embeds fill their frames
9. Theme switch still recolors prose tokens
